### Operational Note

The Radarr webhook endpoint exists unconditionally but depends on `USE_NEW_HANDLER=true` to function. This is an operational consideration — the feature flag must be enabled in `.env` before configuring Radarr to send webhooks. The code gracefully handles the None case (logs error, returns) rather than crashing.

**Recommendation:** Set `USE_NEW_HANDLER=true` in `.env` before configuring Radarr webhook. Alternatively, add a startup guard or HTTP 503 response when HardlinkService is unavailable to make the failure visible.
