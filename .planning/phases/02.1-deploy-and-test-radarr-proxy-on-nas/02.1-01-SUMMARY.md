# Phase 02.1: Deploy and Test Radarr Proxy on NAS Summary

**Zero-downtime canary deploy of Radarr proxy to NAS with port-based media type detection fix for t=search requests**

## Performance

- **Duration:** ~30 min
- **Tasks:** 3
- **Files modified:** 4

## Accomplishments
- Deployed Phase 2 Radarr proxy code to NAS with canary validation strategy
- Validated movie search (port 8587) and TV search (port 8585/8586) normalization
- Discovered and fixed bug: Radarr sends `t=search` not `t=movie` for text searches, causing movies to be normalized as TV
- Added `PORT_MEDIA_TYPES` env var for port-based media type override
- Rollback image tagged as `prowlarr-llm-proxy:rollback`

## Task Commits

1. **Task 1: Zero-downtime deploy to NAS** - (deployment only, no code commit)
2. **Task 2: Validate movie and TV searches** - (validation only, no code commit)
3. **Task 3: Verify deployment** - user approved after fix

**Bug fix:** `786360f` (fix: use port-based media type detection for ambiguous t=search requests)

## Files Created/Modified
- `app/config.py` - Added PORT_MEDIA_TYPES setting and get_port_media_types() method
- `app/services/proxy.py` - Updated _get_media_type() to use port-based detection for t=search
- `app/container.py` - Wired port_media_types into ProxyService
- `tests/test_proxy.py` - Added 5 tests for port-based media type detection

## Decisions Made
- Radarr sends `t=search` for text queries, not `t=movie` — port-based override needed
- NAS .env ROUTES: port 8587 points to Prowlarr (9696) since proxy intercepts Torznab
- Most Prowlarr indexers (1-8) are disabled; only indexer 9 (RuTracker Anime) returned results

## Deviations from Plan

### Auto-fixed Issues

**1. Radarr sends t=search, not t=movie for text searches**
- **Found during:** Task 2 (validation)
- **Issue:** Movies like "Dunkirk" got S01E01 episode markers because t=search defaulted to TV
- **Fix:** Added PORT_MEDIA_TYPES env var; port 8587 always uses movie prompt for ambiguous searches
- **Files modified:** app/config.py, app/services/proxy.py, app/container.py, tests/test_proxy.py
- **Verification:** "Dunkirk (2017) [IMAX] [Bluray-1080p][RU][EN]" — correct movie format
- **Committed in:** 786360f

**2. ROUTES port 8587 target corrected**
- **Found during:** Task 1 (deployment)
- **Issue:** Plan assumed 8587 → Radarr (7878), but proxy needs to intercept via Prowlarr (9696)
- **Fix:** Updated NAS .env ROUTES to point 8587 → Prowlarr 9696
- **Verification:** Searches return Prowlarr-proxied results

---

**Total deviations:** 2 auto-fixed (1 bug fix, 1 config correction)
**Impact on plan:** Bug fix was essential for correctness. Config fix necessary for proxy to work.
