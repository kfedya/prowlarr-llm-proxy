## Why this replaces the original 06-02

Original 06-02 assumed hardlinks would be placed directly in `/data/tv/{Series}/Season NN/` and `/data/movies/{Movie}/`.
This is wrong: Sonarr/Radarr want to **import** files themselves (rename, move, update database).
Putting files in the library directly bypasses import and leaves Sonarr/Radarr unaware of them.

Correct approach: hardlink into a staging path (`/data/downloads/hardlinks/`), configure Remote Path Mapping,
let Sonarr/Radarr import from there via manual or auto import.

        return

    # 5. Process subtitles with LLM normalization
    await self._process_subtitles(

**4g. Add `_compute_movie_hardlink_pairs()`:**

```python
@staticmethod
def _compute_movie_hardlink_pairs(
    files_on_disk: list[Path],
    save_path: Path,
    movie_title: str,
    year: int | None,
    hardlink_base: Path,
) -> list[tuple[Path, Path]]:
    safe_title = MediaHandlerService._sanitize_title(movie_title)
    folder = f"{safe_title} ({year})" if year else safe_title

    pairs = []
    for src in files_on_disk:
        # Preserve torrent-relative path under the movie folder
        # e.g. save_path=/data/downloads/, src=/data/downloads/Movie.2024/Movie.mkv
        # relative = Movie.2024/Movie.mkv -> dst = hardlink_base/Movie (2024)/Movie.2024/Movie.mkv
        # OR for single-file: src=/data/downloads/Movie.mkv -> relative = Movie.mkv
        try:
            relative = src.relative_to(save_path)
        except ValueError:
            relative = Path(src.name)
        dst = hardlink_base / folder / relative
        pairs.append((src, dst))
    return pairs
```
